# report-template.html

This is the **static report template** for AIVI practice reports.

- Per-practice report pages are **generated** from this template by filling the
  `<script id="aivi-data">` JSON block with that practice's data.
- Generated pages will live at `/r/{token}.html`.
- The generator **does not exist yet** — this file is the source template it will
  consume, not itself a served page.

Do not edit generated output here; edit this template and regenerate.
